README file

Generation of optical data from victre-based optical digital phantom. Reconstruction with FEM-based 2-region model.

To run the simulation and reconstruction the file run_victre should be run in matlab.  
The script should first be amended by inserting the pathnames of optical ground truth and prior that one wanst to use in reconstruction.
 

The script requires the installation of the software suite SOLUS in https://github.com/giudisciacca/CLUSTER_COMPUTATION/tree/master/SOLUS and of the software TOAST++
